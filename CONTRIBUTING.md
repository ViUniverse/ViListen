# Contributing

We welcome contributions to this project!

## Developer Certificate of Origin (DCO)

To ensure that all contributions are appropriately licensed, we enforce the Developer Certificate of Origin (DCO) Version 1.1 (see `DCO`).

All commits must be signed-off by the author. By signing off your commit, you certify that you have the right to submit the code under the project's license.

To sign off your commit, simply use the `-s` flag when committing:
```bash
git commit -s -m "Your commit message"
```
This will automatically append a `Signed-off-by: Your Name <your.email@example.com>` to your commit message.
